Support

Need help with FlashStory Chinese? We can help with account access, subscriptions, purchases, saved vocabulary, Practice, reading, or other app issues.

Before contacting support

  • Make sure you are using the latest available version of FlashStory Chinese.
  • If a purchase is missing, try Restore Purchases in Settings.
  • For App Store billing, cancellation, or refund questions, use Apple’s subscription and purchase-management tools.

Contact support

For now, support requests can be submitted through our public GitHub support tracker.

Open a support request

Please do not post passwords, authentication codes, payment details, or other sensitive personal information in a public issue.

Privacy or account deletion

Account deletion is available inside FlashStory Chinese. For privacy-related questions, use the support link above and avoid including sensitive information in the public issue.
