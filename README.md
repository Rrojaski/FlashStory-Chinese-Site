# FlashStory Chinese Site

Public legal and support pages for FlashStory Chinese.

Pages:
- Home: `index.html`
- Privacy Policy: `privacy.html`
- Terms of Use: `terms.html`
- Support: `support.html`

## GitHub Pages

In GitHub, open **Settings → Pages** and publish from the `main` branch at the repository root.

This site is intentionally static and has no build step.
